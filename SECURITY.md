# Security policy

Vault is currently a beta and has not received an independent security audit. Review [the security design](docs/SECURITY.md) and [test report](docs/TEST_REPORT.md) before using it.

Only the latest beta is maintained. Do not post real credentials, master passwords, vault files, private keys or exploitable vulnerability details in public issues. Use GitHub's **Security → Report a vulnerability** if private vulnerability reporting is available. Otherwise open a minimal issue asking the maintainer for a private reporting channel, without disclosing the vulnerability itself.

No response-time guarantee is offered. Fixes and known limitations are documented in the changelog and release notes.
