Cocoa Platform Plugin

Allows Qt to integrate into Apple's Cocoa API.

Code used in the Qt Platform Abstraction (QPA) for macOS.

The sources can be found in qtbase/src/plugins/platforms/cocoa/qcocoaapplication.h, qtbase/src/plugins/platforms/cocoa/qcocoaapplication.mm, qtbase/src/plugins/platforms/cocoa/qcocoaapplicationdelegate.h, qtbase/src/plugins/platforms/cocoa/qcocoaapplicationdelegate.mm, qtbase/src/plugins/platforms/cocoa/qcocoaeventdispatcher.h, qtbase/src/plugins/platforms/cocoa/qcocoaeventdispatcher.mm, qtbase/src/plugins/platforms/cocoa/qcocoaintrospection.h, qtbase/src/plugins/platforms/cocoa/qcocoaintrospection.mm, and qtbase/src/plugins/platforms/cocoa/qcocoasystemtrayicon.mm.
