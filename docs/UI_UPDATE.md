# Interface update · 0.1.0-beta.3

28 September 2026. The shared PySide6 interface serves macOS, Windows and Linux; Android and Chrome receive matching visual changes.

- Desktop: calmer list selection, single-letter avatars, website context, grouped login details, compact count, search icon, refined forms and five themes.
- Android: aligned Graphite/Paper palettes, rounded touch controls with ripple feedback, grouped username/password actions and clearer primary buttons.
- Chrome: automatic light/dark appearance, restrained account rows, state-aware connection indicator and visible keyboard focus.

Local verification: 47 Python tests and 7 Node tests passed. Android's 14 JVM/Robolectric tests and lint passed; library and account-detail previews were rendered. Five desktop theme previews were inspected. Chrome popup was inspected with fictional accounts and simulated extension messaging. This visual update does not constitute an independent security audit or real-device Autofill validation.
