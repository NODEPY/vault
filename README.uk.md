# Vault

**Твої паролі. Твій пристрій. Твій вибір.**

Локальний менеджер паролів для macOS, Windows, Linux та Android із розширенням для Chrome. Без акаунта, підписки, телеметрії та власного хмарного сервісу.

![Vault із вигаданими обліковими записами](docs/images/vault-dark.png)

П’ять мов і п’ять тем, генератор паролів та парольних фраз, пошук, автоматичне блокування, зашифровані резервні копії. Chrome заповнює форми на твою команду та просить підтвердити збереження. Android підтримує роботу із записами й автозаповнення сумісних форм нативних застосунків.

[Встановлення для кожної ОС](docs/INSTALL.md) · [Звіт перевірок](docs/TEST_REPORT.md) · [Як захищені дані](docs/SECURITY.md) · [English](README.md)

Ключ виводиться з майстер-пароля через Argon2id; файл захищений Fernet (AES-128-CBC + HMAC-SHA256). Код відкритий за MIT, перевірки та параметри шифрування можна переглянути. Це підстава для перевірки, а не обіцянка абсолютної безпеки: незалежного аудиту ще немає.

Це **бета**. Повний сценарій Chrome та Android Autofill на реальному пристрої ще потребує перевірки. Mac-пакет без нотаризації Apple, APK підписаний тестовим ключем. Стан кожної платформи наведено у звіті. Майстер-пароль неможливо відновити: скидання видаляє локальне сховище. Зберігай зашифровані резервні копії та пам’ятай їхній пароль.
