# Changelog

## 0.1.0-beta.3 — 28 September 2026

- Refined desktop list, account identity and website display, form spacing and all five themes.
- Grouped Android login fields and actions, improved touch feedback and primary buttons.
- Redesigned Chrome popup with system light/dark appearance, clearer connection status and account rows.

# 0.1.0-beta.2

- Desktop Vault for macOS, Windows and Linux; native Android app with compatible encrypted backups.
- English by default, plus Ukrainian, Polish, German and Spanish; five coordinated themes.
- First-run setup, master password creation/unlock, typed destructive reset, settings and session locking.
- Create/edit/delete/search entries, random password and desktop passphrase generation, timed password reveal and clipboard ownership checks.
- Encrypted backup export and merge import; migration of existing records without website fields.
- Chrome Companion: explicit site permissions, exact HTTPS matching, visible-form capture and user-triggered fill through the unlocked desktop app.
- Android native-app Autofill with master unlock and package/signing-certificate association.
- Cross-platform build workflow, privacy/security documentation, dependency notices and repeatable tests.

See docs/RELEASE_STATUS.md for verification limits and publisher-owned signing steps.
